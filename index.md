# Programowanie obiektowe w Javie

Instrukcje do przedmiotu **Programowanie obiektowe** na kierunku
**Informatyka i ekonometria**, III semestr, rok akademicki 2026/2027.
Pracujemy w IntelliJ IDEA i Mavenie. Projekt semestralny to desktopowa
aplikacja Java z interfejsem graficznym i analizą danych ekonomicznych lub
ekonometrycznych.

## Laboratoria

| Lab | Temat | Spotkania |
|---|---|---:|
| [Lab 1](./2026-2027/lab1/README.html) | Swing: układy, formularze, tabele i rysowanie | 3 |
| [Lab 2](./2026-2027/lab2/README.html) | JavaFX: scena, formularze, wykresy i FXML/MVC | 4 |
| [Lab 3](./2026-2027/lab3/README.html) | JDBC: SQL, DAO, CRUD, relacje i transakcje | 3 |
| [Lab 4](./2026-2027/lab4/README.html) | Hibernate i mapowanie obiektowo-relacyjne | 2 |
| [Lab 5](./2026-2027/lab5/README.html) | JSP i Servlet API | 1 |
| [Lab 6](./2026-2027/lab6/README.html) | Integracja aplikacji i obrona projektu | 1 |
