# Programowanie obiektowe w języku Java

Instrukcje do przedmiotu **Programowanie obiektowe** na kierunku
**Informatyka i ekonometria**, III semestr, rok akademicki 2026/2027.
Projekty należy tworzyć w IntelliJ IDEA z użyciem Mavena. Projekt semestralny
ma postać desktopowej aplikacji Java z interfejsem graficznym i analizą danych
ekonomicznych lub ekonometrycznych.

## Laboratoria

| Lab | Temat | Projekt do otwarcia w IntelliJ IDEA |
|---|---|---|
| [Lab 1](./2026-2027/lab1/README.html) | Swing: układy, formularze, tabele i rysowanie | [Projekt startowy](./2026-2027/lab1/projekt-startowy.zip), [galeria układów](./2026-2027/lab1/demo/galeria-swing.zip) |
| [Lab 2](./2026-2027/lab2/README.html) | JavaFX: scena, formularze, wykresy i FXML/MVC | [Projekt startowy](./2026-2027/lab2/projekt-startowy.zip), [Layout Explorer](./2026-2027/lab2/demo/layout-explorer.zip) |
| [Lab 3](./2026-2027/lab3/README.html) | JDBC: SQL, DAO, CRUD, relacje i transakcje | [Projekt do modyfikacji](./2026-2027/lab3/demo/projekt-do-modyfikacji.zip) |
| [Lab 4](./2026-2027/lab4/README.html) | Hibernate i mapowanie obiektowo-relacyjne | [Projekt do modyfikacji](./2026-2027/lab4/demo/projekt-do-modyfikacji.zip) |
| [Lab 5](./2026-2027/lab5/README.html) | JSP i Servlet API | [Projekt do modyfikacji](./2026-2027/lab5/demo/projekt-do-modyfikacji.zip) |
| [Lab 6](./2026-2027/lab6/README.html) | Integracja aplikacji i obrona projektu | Kontynuacja projektu z Lab 3 lub Lab 4 |
