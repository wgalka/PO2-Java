Lab 8: Comprehensive Guide to JavaFX & Hibernate

This tutorial is a deep dive into building professional desktop applications with Java. We will move beyond simple coding and explore Software Architecture, Design Patterns, and Data Persistence.

By the end of this lab, you will understand how to build a scalable Student Management System using JavaFX 24 and Hibernate 6.6.

1. Project Architecture: The "Why"

Before we write a single line of code, we must understand how to organize it. A professional application is divided into layers. This is called Separation of Concerns.

The Layered Pattern

  1. Model Layer: Represents the data (e.g., a "Student"). It's a simple Java class that maps to a database table.

  1. Repository Layer (DAO - Data Access Object): The only layer that talks to the database. It handles raw "Create, Read, Update, Delete" (CRUD) operations.

  1. Service Layer: The "Brain" of the app. It holds business logic (e.g., "Is this email valid?") and uses the Repository to save data.

  1. Controller Layer: Handles the user interface (UI). It reacts to button clicks and tells the Service what to do.

SOLID Principles in Practice

It follows the SOLID principles of object-oriented design:

  • S - Single Responsibility: Each class has one reason to change. The StudentService only changes if business rules change, while the StudentRepository only changes if the database logic changes.
  • O - Open/Closed: Our code is open for extension but closed for modification. We can add a TeacherRepository by implementing the Repository interface without changing existing code.
  • L - Liskov Substitution: We can swap any Repository implementation (e.g., H2 vs. MySQL) and the StudentService will still work perfectly because they share the same contract.
  • I - Interface Segregation: We use a focused Repository interface so that classes only depend on methods they actually use.
  • D - Dependency Inversion: The StudentService depends on the Abstraction (Repository interface), not the Implementation (StudentRepository). We "inject" the dependency, decoupling the high-level logic from low-level data access.

Why use this?

  • Maintainability: If you change your database from H2 to PostgreSQL, you only change the Repository, not the whole app.
  • Testability: You can test the Service logic without even having a database!

3. The Data Layer (ORM)

What is an Entity?

An Entity is a Java class that Hibernate "tracks." We use annotations: - @Entity: Marks the class for Hibernate. - @Id: Defines the primary key. - @GeneratedValue: Tells the database to increment the ID automatically (1, 2, 3...).

Encapsulation

Notice that fields like private String firstName; are private. This is Encapsulation. We control access to data through methods, preventing other classes from accidentally corrupting the state of our object.

Model - Student.java 
package org.example.app.models;

import jakarta.persistence.*;
import lombok.*;

@Data
@Entity
public class Student {
    @Id
    @GeneratedValue(strategy = GenerationType.IDENTITY)
    private Long id;

    @Column(nullable = false)
    private String firstName;

    @Column(nullable = false)
    private String lastName;

    @Column(unique = true, nullable = false)
    private String email;

    public Student() {}

    public Student(String firstName, String lastName, String email) {
        this.firstName = firstName;
        this.lastName = lastName;
        this.email = email;
    }
}

4. The Repository Pattern

Instead of writing Hibernate code directly in the UI, we create a StudentRepository.

The Generic Interface: We use a Generic Interface Repository<T, ID>. This is an example of Polymorphism. We can have one interface that works for Students, Teachers, or Courses.

public interface Repository<T, ID> {
    Optional<T> findById(ID id);
    List<T> findAll();
    void save(T entity);
    void delete(T entity);
}
Generic Repository - Repository.java 
package org.example.app.repositories;

import java.util.List;
import java.util.Optional;

public interface Repository<T, ID> {
    Optional<T> findById(ID id);
    List<T> findAll();
    void save(T entity);
    void delete(T entity);
}
Implementation - StudentRepository.java 
package org.example.app.repositories;

import org.example.app.models.Student;
import org.example.app.utils.HibernateUtil;
import org.hibernate.Session;
import org.hibernate.Transaction;
import java.util.List;
import java.util.Optional;

public class StudentRepository implements Repository<Student, Long> {

    @Override
    public Optional<Student> findById(Long id) {
        try (Session session = HibernateUtil.getSessionFactory().openSession()) {
            return Optional.ofNullable(session.get(Student.class, id));
        }
    }

    @Override
    public List<Student> findAll() {
        try (Session session = HibernateUtil.getSessionFactory().openSession()) {
            return session.createQuery("from Student", Student.class).list();
        }
    }

    @Override
    public void save(Student student) {
        Transaction transaction = null;
        try (Session session = HibernateUtil.getSessionFactory().openSession()) {
            transaction = session.beginTransaction();
            session.merge(student);
            transaction.commit();
        } catch (Exception e) {
            if (transaction != null) transaction.rollback();
            throw e;
        }
    }

    @Override
    public void delete(Student student) {
        Transaction transaction = null;
        try (Session session = HibernateUtil.getSessionFactory().openSession()) {
            transaction = session.beginTransaction();
            session.remove(session.contains(student) ? student : session.merge(student));
            transaction.commit();
        } catch (Exception e) {
            if (transaction != null) transaction.rollback();
            throw e;
        }
    }
}
Utility - HibernateUtil.java 
package org.example.app.utils;

import org.hibernate.SessionFactory;
import org.hibernate.cfg.Configuration;

5. The Service Layer & Dependency Injection (DI)

What is Dependency Injection?

If StudentService needs a StudentRepository, we don't create it inside the service. We inject it through the constructor. Why? Because it makes the code flexible. You can "inject" a real database repository or a "fake" one for testing.

The service is where we validate data. For example, before saving a student, we check if the email follows a specific pattern (Regex).

Service - StudentService.java 
package org.example.app.services;

import org.example.app.models.Student;
import org.example.app.repositories.Repository;
import java.util.List;

public class StudentService {
    private final Repository<Student, Long> studentRepository;

    public StudentService(Repository<Student, Long> studentRepository) {
        this.studentRepository = studentRepository;
    }

    public List<Student> getAllStudents() {
        return studentRepository.findAll();
    }

    public void addStudent(Student student) {
        validateStudent(student);
        studentRepository.save(student);
    }

    public void removeStudent(Student student) {
        studentRepository.delete(student);
    }

    public void duplicateStudent(Student original) {
        Student copy = new Student(original.getFirstName(), original.getLastName(), original.getEmail());
        studentRepository.save(copy);
    }

    private void validateStudent(Student s) {
        if (s.getFirstName() == null || s.getFirstName().isBlank()) {
            throw new IllegalArgumentException("First name is required.");
        }
        if (s.getLastName() == null || s.getLastName().isBlank()) {
            throw new IllegalArgumentException("Last name is required.");
        }
        if (s.getEmail() == null || !s.getEmail().matches("^[A-Za-z0-9+_.-]+@(.+)$")) {
            throw new IllegalArgumentException("Invalid email format.");
        }
    }
}

7. Advanced UI Logic

FilteredList (Search)

Instead of querying the database every time a user types a letter, we wrap our main list in a FilteredList. As the user types, we change the "Predicate" (the rule) of the list, and the TableView updates instantly!

Pagination

If you have 1000 students, you don't want to scroll forever. 1. We decide on a page size (e.g., 5 rows). 2. The Pagination control provides a pageIndex. 3. We calculate: fromIndex = pageIndex * pageSize. 4. We show only that "slice" of data in the table.

By adding a ContextMenu to a TableRow, we provide a better User Experience (UX). Users can right-click to perform quick actions like Duplicating a record.

Main Controller - MainController.java 
package org.example.app.controllers;

import javafx.collections.FXCollections;
import javafx.collections.ObservableList;
import javafx.collections.transformation.FilteredList;
import javafx.collections.transformation.SortedList;
import javafx.fxml.FXML;
import javafx.fxml.FXMLLoader;
import javafx.scene.Parent;
import javafx.scene.Scene;
import javafx.scene.control.*;
import javafx.scene.control.cell.PropertyValueFactory;
import javafx.stage.Modality;
import javafx.stage.Stage;
import org.example.app.App;
import org.example.app.models.Student;
import org.example.app.services.StudentService;
import java.io.IOException;

public class MainController {
    @FXML private TableView<Student> studentTable;
    @FXML private TableColumn<Student, Long> idCol;
    @FXML private TableColumn<Student, String> firstNameCol;
    @FXML private TableColumn<Student, String> lastNameCol;
    @FXML private TableColumn<Student, String> emailCol;
    @FXML private TextField searchField;
    @FXML private Pagination pagination;

    private static final int ROWS_PER_PAGE = 5;
    private final ObservableList<Student> studentList = FXCollections.observableArrayList();
    private FilteredList<Student> filteredData;
    private final StudentService studentService = App.getStudentService();

    @FXML
    public void initialize() {
        idCol.setCellValueFactory(new PropertyValueFactory<>("id"));
        firstNameCol.setCellValueFactory(new PropertyValueFactory<>("firstName"));
        lastNameCol.setCellValueFactory(new PropertyValueFactory<>("lastName"));
        emailCol.setCellValueFactory(new PropertyValueFactory<>("email"));

        filteredData = new FilteredList<>(studentList, p -> true);

        searchField.textProperty().addListener((observable, oldValue, newValue) -> {
            filteredData.setPredicate(student -> {
                if (newValue == null || newValue.isEmpty()) return true;
                String lowerCaseFilter = newValue.toLowerCase();
                return student.getFirstName().toLowerCase().contains(lowerCaseFilter) ||
                       student.getLastName().toLowerCase().contains(lowerCaseFilter) ||
                       student.getEmail().toLowerCase().contains(lowerCaseFilter);
            });
            updatePagination();
        });

        setupContextMenu();
        pagination.setPageFactory(this::createPage);
        refreshData();
    }

    private void setupContextMenu() {
        studentTable.setRowFactory(tv -> {
            TableRow<Student> row = new TableRow<>();
            ContextMenu contextMenu = new ContextMenu();
            MenuItem duplicateItem = new MenuItem("Duplicate");
            duplicateItem.setOnAction(event -> {
                studentService.duplicateStudent(row.getItem());
                refreshData();
            });
            MenuItem deleteItem = new MenuItem("Delete");
            deleteItem.setOnAction(event -> handleDelete());
            contextMenu.getItems().addAll(duplicateItem, deleteItem);
            row.contextMenuProperty().bind(
                javafx.beans.binding.Bindings.when(row.emptyProperty())
                .then((ContextMenu)null)
                .otherwise(contextMenu)
            );
            row.setOnMouseClicked(event -> {
                if (event.getClickCount() == 2 && (!row.isEmpty())) {
                    showDetails(row.getItem());
                }
            });
            return row;
        });
    }

    private javafx.scene.Node createPage(int pageIndex) {
        int fromIndex = pageIndex * ROWS_PER_PAGE;
        int toIndex = Math.min(fromIndex + ROWS_PER_PAGE, filteredData.size());
        if (fromIndex >= filteredData.size() && filteredData.size() > 0) return new Label("No data");
        SortedList<Student> sortedData = new SortedList<>(
                FXCollections.observableArrayList(filteredData.subList(fromIndex, toIndex))
        );
        sortedData.comparatorProperty().bind(studentTable.comparatorProperty());
        studentTable.setItems(sortedData);
        return new Label("Page " + (pageIndex + 1));
    }

    private void updatePagination() {
        int pageCount = (int) Math.ceil((double) filteredData.size() / ROWS_PER_PAGE);
        pagination.setPageCount(pageCount == 0 ? 1 : pageCount);
        int currentPage = pagination.getCurrentPageIndex();
        pagination.setPageFactory(null);
        pagination.setPageFactory(this::createPage);
        pagination.setCurrentPageIndex(currentPage);
    }

    private void refreshData() {
        studentList.setAll(studentService.getAllStudents());
        updatePagination();
    }

    @FXML
    private void handleAdd() {
        try {
            FXMLLoader loader = new FXMLLoader(getClass().getResource("/org/example/app/views/student-edit-view.fxml"));
            Parent root = loader.load();
            Stage stage = new Stage();
            stage.setTitle("Add New Student");
            stage.initModality(Modality.APPLICATION_MODAL);
            stage.setScene(new Scene(root));
            stage.showAndWait();
            refreshData();
        } catch (IOException e) {
            e.printStackTrace();
        }
    }

    @FXML
    private void handleDelete() {
        Student selected = studentTable.getSelectionModel().getSelectedItem();
        if (selected == null) return;
        Alert alert = new Alert(Alert.AlertType.CONFIRMATION, "Delete student " + selected.getFirstName() + "?");
        if (alert.showAndWait().orElse(ButtonType.CANCEL) == ButtonType.OK) {
            studentService.removeStudent(selected);
            refreshData();
        }
    }

    private void showDetails(Student s) {
        Alert info = new Alert(Alert.AlertType.INFORMATION);
        info.setTitle("Student Details");
        info.setHeaderText(s.getFirstName() + " " + s.getLastName());
        info.setContentText("ID: " + s.getId() + "\nEmail: " + s.getEmail());
        info.show();
    }

    @FXML
    private void handleExit() { System.exit(0); }
}

Entry Point - App.java 
package org.example.app;

import javafx.application.Application;
import javafx.fxml.FXMLLoader;
import javafx.scene.Parent;
import javafx.scene.Scene;
import javafx.stage.Stage;
import org.example.app.models.Student;
import org.example.app.repositories.StudentRepository;
import org.example.app.services.StudentService;
import org.example.app.utils.HibernateUtil;
import org.hibernate.Session;
import org.hibernate.Transaction;
import java.io.IOException;

public class App extends Application {
    private static StudentService studentService;

    public static void main(String[] args) {
        studentService = new StudentService(new StudentRepository());
        seedData();
        launch();
    }

    public static StudentService getStudentService() {
        return studentService;
    }

    @Override
    public void start(Stage stage) throws IOException {
        FXMLLoader loader = new FXMLLoader(getClass().getResource("/org/example/app/views/main-view.fxml"));
        Parent root = loader.load();
        Scene scene = new Scene(root);
        stage.setTitle("Student Management System");
        stage.setScene(scene);
        stage.show();
    }

    private static void seedData() {
        try (Session session = HibernateUtil.getSessionFactory().openSession()) {
            Long count = session.createQuery("select count(s) from Student s", Long.class).uniqueResult();
            if (count == 0) {
                Transaction tx = session.beginTransaction();
                session.persist(new Student("John", "Doe", "john@example.com"));
                session.persist(new Student("Jane", "Smith", "jane@example.com"));
                tx.commit();
            }
        }
    }

    @Override
    public void stop() {
        HibernateUtil.shutdown();
    }
}
